# UniOS Learning Intelligence (AI/ML-2)

Service responsible for understanding the learner and generating adaptive pedagogy, structured lessons, learner memory intelligence, and roadmap adaptation for the UniOS ecosystem.

---

## Architectural Role & Ownership Boundaries

- **AI/ML-2 (This Service) Owns:**
  - Learner Profile & Onboarding Intelligence
  - Multi-Facet Learner Memory Intelligence
  - Context Retrieval & Evidence-Driven Memory Updates
  - Pedagogical Decisions & Adaptive Lesson Generation
  - Roadmap Adaptation Intelligence
- **AI/ML-1 Owns:** KIE core orchestration, intent routing, agent coordination, and roadmap planning execution.
- **Backend Owns:** User authentication, authorization, and persistent database storage.
- **Frontend Owns:** Client UI rendering and `LessonRenderer` (no raw UI code generated by AI/ML-2).

## Sprint 3 Capabilities: Memory Engine + Context Retrieval

### 1. The 7 Memory Dimensions
Located in `app/schemas/memory.py`:
1. **Preferences**: Cognitive modalities (`visual`, `hands-on`, `theoretical`, `interactive`), pacing velocity (`fast`, `standard`, `deliberate`), practical vs. theory ratio, and feedback frequency.
2. **Conversations**: Q&A signals, sentiment markers (`curious`, `confused`, `frustrated`), and concept confusions.
3. **Learning History**: Completed units, assessment scores ($0.0 - 1.0$), attempts, time spent, and mastery levels (`novice`, `competent`, `proficient`, `mastered`).
4. **Projects**: Practical projects attempted/completed, technologies used, and complexity tiers (`beginner`, `intermediate`, `advanced`).
5. **Goals**: Primary target career role, target timeline in months, milestone checklists, and goal change audit log.
6. **Achievements**: Auto-awarded and milestone badges (mastery, streak, project builder).
7. **Friction**: Unresolved struggles, error compounding, severity tiers (`low`, `moderate`, `high`), and pedagogical intervention recommendations.

### 2. Evidence-Driven Memory Updates & Threshold Rules
Located in `app/schemas/memory_events.py` & `app/services/memory_engine.py`:
- **Credibility Classification**: Distinguishes `explicit` declarations, `observed` platform telemetry, and `inferred` heuristic signals with confidence scores ($0.0 - 1.0$).
- **Friction Escalation & De-escalation Thresholds**:
  - **Poor assessment score (`score < 0.50`)**: Escalates friction severity and mistake counter.
  - **Boundary score (`score == 0.85`)**: Strictly does **NOT** resolve active friction.
  - **High performance score (`score > 0.85`, e.g. `0.86+`)**: Resolves active friction, marks `unresolved=False`, and updates mastery level.
  - Repeated mistakes (count $\ge 3$) escalate friction severity to `high`.

### 3. Onboarding → Memory Seeding Flow
- **`POST /api/v1/memory/seed`** (and alias `/seed-from-onboarding`):
  - Bridges the 6-D `LearnerIntelligenceReport` generated by Onboarding into the `LearnerMemory` container.
  - Seeds target role, timelines, cognitive preferences, pacing, format priorities, and prerequisite health.
  - Operates idempotently: sets `is_new_initialization=True` on first run, and safely updates preferences without overwriting historical learner evidence or achievements on subsequent calls.

### 4. Relevant Memory Context Retrieval
- **`GET /api/v1/memory/{learner_id}/relevant`** & **`POST /api/v1/memory/relevant-context`**:
  - Scopes learner memory specifically to an upcoming topic and objective without dumping full raw history into LLM prompts.
  - Filters active friction, related past units, relevant projects, active career goals, and preferred learning modality.
  - Safe fallback: For unknown or new learners, returns a clean baseline `RelevantMemoryContext` without failing.

### 5. Memory Context Enrichment in Lesson Planning
- **`POST /api/v1/learning/plan-lesson`**:
  - Accepts optional `memory_context: Optional[RelevantMemoryContext] = None` in `NormalizedLearningContext`.
  - **Dual Support Flow**:
    - **A. Explicit `memory_context`**: Directly utilizes caller-supplied memory context.
    - **B. Automatic Retrieval**: If `memory_context` is omitted but `learner_id` is present in `learner_state`, automatically queries `MemoryEngine.retrieve_relevant_context()` for the lesson topic and objective.
  - **Graceful Fallbacks**:
    - Unknown learner &rarr; plans lesson using baseline context.
    - Empty memory &rarr; continues with standard pedagogy.
    - Retrieval error &rarr; falls back gracefully without interrupting lesson delivery.
  - **Active Friction &rarr; Remediation Pedagogy**:
    - When active friction on the topic is present, `PedagogyEngine` automatically selects `TeachingStrategy.REMEDIATION`.
    - Adjusts pacing to deliberate, increases visual/worked-example scaffolding, and lowers cognitive load.

### 6. Read-Only Memory Inspection Endpoints
- **`GET /api/v1/memory/{learner_id}`**:
  - Non-mutating read-only endpoint returning the full 7-dimension `LearnerMemory` container.
  - Returns HTTP 200 with complete structured model for existing learners.
  - Returns HTTP 404 (`Learner memory not found`) for unknown learners.
- **`GET /api/v1/memory/{learner_id}/relevant`**:
  - Query parameters: `topic` (string) and `objective` (string).
  - Returns scoped `RelevantMemoryContext` matching the exact context used by lesson planning.

      "recommended_foundation_topics": ["Linear Algebra"]

    "learning_style": {
      "dominant_modality": "hands-on",
      "secondary_modality": "visual",
      "recommended_pacing": "standard",

    "career_goals": {

### 2. Inspect Full Memory Container
**`GET /api/v1/memory/{learner_id}`**
```bash
curl -X GET "http://localhost:8000/api/v1/memory/student_101"
```
*Response: HTTP 200 with full 7-dimension `LearnerMemory` JSON object.*

### 3. Inspect Scoped Relevant Memory Context
**`GET /api/v1/memory/{learner_id}/relevant`**
```bash
curl -X GET "http://localhost:8000/api/v1/memory/student_101/relevant?topic=Neural%20Networks&objective=Understand%20Backpropagation"
```
*Response: HTTP 200 with scoped `RelevantMemoryContext`.*

### 4. Plan Adaptive Lesson (with Enriched Memory)
**`POST /api/v1/learning/plan-lesson`**
```bash
curl -X POST "http://localhost:8000/api/v1/learning/plan-lesson" \
  -H "Content-Type: application/json" \
  -d '{
    "context_id": "ctx_nn_01",
    "learner_state": {
      "learner_id": "student_101",
      "stage": "bachelor",
      "weaknesses": ["Backpropagation"],
      "strengths": ["Python"],
      "confidence_level": "low"
    },
    "topic": "Neural Networks",
    "learning_objective": "Understand Backpropagation and Gradient Descent",
    "constraints": {
      "max_blocks": 5,
      "include_practice": true
    }
  }'
```
*Automatically retrieves `student_101` memory, detects friction, and applies `TeachingStrategy.REMEDIATION`.*
